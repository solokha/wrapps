# AGENTS.md — wrapps

Публичный репозиторий: переносимое окружение NixOS и обёртки приложений
(десктоп-экспорт). Макет, пакеты, команды и правила публичности — `README.md`,
он же первичная документация.

Уровень: `$HARNESS_DIR/AGENTS.md` (слой инструментов) → AGENTS.md рабочего
каталога (`harness/adapters/lab-workspace/AGENTS.md`) → этот файл; побеждает
ближайший к изменяемому файлу. Здесь намеренно нет фактуры лаборатории —
сетей, дисков, хостов, секретов: она живёт в приватном `infra`.

## Устройство

- `flake.nix` — flake-parts; пакеты собирает `callModule` по файлам в
  `modules/` (`firefox`, `zed`, `fuzzel`, `niri`, …); `nixosModules.desktop`
  ставит их на хост; `overlay.nix` отдаёт пакеты оверлеем.
- Новый пакет — один файл в `modules/` плюс строка в `README.md`.
- Пер-хостовые значения — только через переменные окружения (`{env:...}`):
  дефолты в репозитории несекретны, это проверяется при каждой правке.

## Git и FIDO2

push и любой доступ к GitHub идут через `wrapps-agent`: диалог PIN, порядок
ключей (`@clone` первым), лечение «смотрит мимо агента» — `README.md`,
раздел «FIDO2». Подписи коммитов выключены — не включать по своей инициативе.

## Проверки

`nix run .#env`, `nix run .#desktop`, `nix flake check` — до коммита.
