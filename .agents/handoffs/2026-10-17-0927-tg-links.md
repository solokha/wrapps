# Handoff: ссылки tg:// в Telegram Web (обработчик схемы)

- Date / host / agent: 2026-10-17 09:27 / rover / opencode (V2)
- Goal: ссылку `https://t.me/+HASH` (и её `tg://join?invite=…`) открывать в
  Telegram Web, когда Telegram работает веб-приложением в Firefox
  (окно-таскбар-вкладка, `web.telegram.org/a/`).
- Done:
  - `modules/firefox.nix`: три pref'а для схемы `tg` — `external.tg = true`,
    `expose.tg = false`, `warn-external.tg = false` (тот же набор, что у `mailto`).
  - `modules/tg-web.nix` (новый): пакет `tg-web` — скрипт-обработчик плюс
    `.desktop` (`NoDisplay=true`, `MimeType=x-scheme-handler/tg`,
    `Exec=…/tg-web %u`). Скрипт берёт `tg://…`, кодирует его целиком
    (`jq -sRr @uri`) и открывает новой вкладкой
    `https://web.telegram.org/a/#?tgaddr=<кодированная ссылка>` в обёрнутом
    firefox из этого же репозитория. Запуск без аргумента открывает клиент.
  - `flake.nix`: пакет `tg-web`, он же в `checks`; в `nixosModules.desktop` —
    `environment.systemPackages` + `xdg.mime.defaultApplications."x-scheme-handler/tg"`.
  - `README.md` / `README.en.md`: раздел «Ссылки Telegram».
- Why так:
  - Firefox сам схему отдать не может: сайту разрешено занять только `web+tg://`,
    а Telegram Web себе его не регистрирует; системного обработчика на хосте не
    было (`gio mime x-scheme-handler/tg` → *No default applications*).
    `expose.tg = false` — это и есть «отдать схему наружу»: `nsDocShell` при
    неэкспонированной схеме уходит в `nsIExternalProtocolService` (проверено по
    исходникам Firefox), то есть клик по ссылке с страницы работает.
  - Кодирование целиком, а не «как есть»: `tgaddr` — параметр в хеше
    (`#?tgaddr=…`), и без кодирования `&`/`+` внутри ссылки ломают разбор
    `URLSearchParams` (`+` вообще читается как пробел). Форма совпадает с той,
    что отдаёт сам Telegram (`z.t.me`).
  - `%u` в `Exec` — без кавычек: glib 2.88 подставляет его как есть, а кавычки
    (в том числе внутри строки вида `"https://…#?tgaddr=%u"`) уезжают в аргумент
    буквально и ломают URL. Поэтому понадобился скрипт-обёртка.
  - Место — `wrapps`, а не `infra`: `Exec` обязан указывать на обёрнутый
    firefox отсюда, а `xdg.mime` — обычная десктопная интеграция.
